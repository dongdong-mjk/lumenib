# lumenib 루메닙

성경 본문 위에 손글씨로 설교 노트를 쓰는 태블릿 앱의 **1차 사용성 테스트용 웹앱**이에요.
피그마의 태블릿 디자인(T1–T7, 다크 모드 기본)을 그대로 옮겼어요. 폰 화면은 아직 없어요.

## 테스트 범위

| 과제 | 화면 |
|---|---|
| 1. 홈에서 "오늘 설교 기록하기"로 본문 고르기 | T1 → T2 → T3 |
| 2. 본문 위에 펜 · 형광펜으로 필기, 지우개 · 올가미 | T4 |
| 3. 설교에 나온 다른 구절을 찾아 노트로 넣기 (버튼 또는 끌어오기) | T5 |
| 4. 같은 본문의 예전 노트를 탭으로 열어 보기 | T6 → T7 |
| 5. 본문 없이 먼저 쓰고, 완료할 때 본문 정하기 → 홈으로 | 본문 없이 쓰기 · 완료 |

테스트 범위 밖(누르면 "1차 테스트에서는 아직 열 수 없어요"): 성경 · 노트 · 북마크 탭, 이어서 읽기, 전체보기, 로그인, 검색, AI 정리본.

## 테스트 진행 팁

- 아이패드 Safari에서 열고 **공유 → 홈 화면에 추가**로 설치하면 주소창 없이 전체 화면으로 열려요.
- 애플펜슬로 쓰고, 손가락으로는 스크롤해요. 펜슬이 없으면 설정(홈 오른쪽 위 톱니)에서 **손가락으로도 필기하기**를 켜요. 켜면 한 손가락은 쓰기, 두 손가락은 스크롤이에요.
- 노트는 그 기기 브라우저에만 저장돼요(서버 없음). 다음 테스터 전에 설정 → **테스트 기록 지우기**를 눌러요.
- 펜 색 바꾸기: 툴바에서 이미 고른 색을 한 번 더 누르면 팔레트(기본 색 = 피그마 pen 12색, 내 색 = 직접 만든 색 최대 6개)가 열려요. 고른 색이 그 칸에 들어가요. 내 색은 길게 눌러 지워요.
- 펜 · 형광펜 · 지우개 굵기를 고르면 종이 위 실제 크기가 잠깐 보여요.
- 홈은 스크롤 없이 화면 높이에 맞춰요. 요소 크기는 시안(1194×834) 그대로이고, 화면이 더 길면 간격이 넓어지고 짧으면 간격부터 줄인 뒤 전체를 살짝 줄여요.
- 지우개는 **획 전체 / 부분** 중에서 골라요. 인용 블록은 오른쪽 위 손잡이(⠿)로 위아래로 옮기고, ×로 뺄 수 있어요.
- 예시 노트(로마서 8:35, 8:37 등)는 미리 넣어 둔 가짜 데이터예요. 손글씨처럼 보이게 손글씨 글꼴(나눔손글씨 펜)로 보여 줘요.
- 홈의 성경 읽기 현황(355/1,189장)도 예시 값이에요.
- 사용 기록은 Microsoft Clarity로 모아요(`js/analytics.js`). 화면 태그 `screen`과 과제 이벤트(task1~5)로 녹화를 걸러 볼 수 있어요. 손글씨(캔버스)는 녹화에 보이지 않아요.

## 구조

```
index.html            시작 화면 (스플래시 → 홈)
css/app.css           색 변수(피그마 Color 변수 이름 그대로, Dark/Light) + 화면 스타일
js/app.js             화면 흐름: 홈, 본문 고르기, 노트 쓰기, 완료
js/biblepanel.js      왼쪽 성경 패널 (권 · 장 · 절 고르기, 검색, 끌어오기)
js/ink.js             손글씨 종이 (펜 · 형광펜 · 지우개 · 올가미 · 되돌리기)
js/store.js           노트 저장(localStorage), 예시 노트, 설정
js/bible.js           성경 데이터 불러오기
data/bible/krv/       개역한글 66권 (books.json + 01.json … 66.json)
fonts/wanted-sans/    Wanted Sans (SIL OFL 1.1)
```

### 성경 번역본 바꾸기

`data/bible/<코드>/` 폴더에 같은 형식(`books.json`, `01.json`…`66.json`)으로 넣고 `js/bible.js`의 `TRANSLATION` 값만 바꾸면 돼요.
지금 데이터: 개역한글(1961), 출처 [bluesaurel/Korean-Bible-1961-KRV](https://github.com/bluesaurel/Korean-Bible-1961-KRV). 저작권 표시: 대한성서공회. 배포 전에는 대한성서공회 안내를 다시 확인해야 해요.

## 로컬에서 열기

```
python3 -m http.server 8000
```
브라우저에서 http://localhost:8000 을 열어요. 빌드 과정은 없어요.

## 아이패드 앱으로 설치하기 (Capacitor, `capacitor-ios` 브랜치)

웹앱을 그대로 감싼 iPad 앱이에요. 앱은 GitHub Pages 주소를 열기 때문에 웹을 고치면 앱에도 바로 반영돼요.
앱에서만 되는 것: **애플펜슬 더블탭(2세대·Pro)과 스퀴즈(Pro)**. iPad 설정 > Apple Pencil에서 고른 동작(지우개로 전환 · 이전 도구 · 색상 팔레트 · 잉크 속성 · 끔)을 그대로 따라가요. 노트 쓰기 화면의 "네이티브 필기" 버튼으로 PencilKit 필기감 비교 화면도 열 수 있어요.

1. App Store에서 Xcode 설치 → 한 번 실행해서 추가 구성요소 설치
2. 터미널에서 `./scripts/prepare-ios.sh` (Node 없이 준비)
3. `open ios/App/App.xcodeproj` → 처음 열면 Capacitor 패키지를 내려받느라 잠깐 기다려요
4. 왼쪽 App → Signing & Capabilities → Team에서 내 Apple ID(Personal Team) 고르기. 번들 ID가 겹친다고 나오면 끝에 글자를 하나 붙이기
5. iPad를 케이블로 연결 → 위쪽 기기 목록에서 iPad 고르기 → ▶ 실행
6. iPad: 설정 > 개인정보 보호 및 보안 > 개발자 모드 켜기(재시동), 설정 > 일반 > VPN 및 기기 관리에서 내 Apple ID 신뢰

무료 Apple ID로 설치한 앱은 7일 뒤에 열리지 않아요. 다시 ▶ 실행하면 7일 연장돼요. 테스터에게 나눠 주려면(TestFlight) 유료 개발자 계정(연 $99)이 필요해요.
